# lucxxer-mods-for-NetFix

Приветы. Первый раз что-то выкладываю на GitHub, не бейте тапками. Здесь я собрал список доменов для обхода блокировок через `NetFix`.

## 🌐 Списки доменов для zapret
*   `Cloudflare и CDN.netfix-mod` — Разблочит домены Cloudflare и поддомены, используемые для сайтов с картинками/гифками.
*   `Focusrite.netfix-mod` — Разблочит домены Focusrite для установки и использования их ПО.
*   `Steelseries.netfix-mod` — Разблочит домены домены Steelseries для установки и использования их ПО.
  
*   `OG Zapret... .netfix-mod` — Это оригинальные списки из Zapret от Flowseal. (Актуальные для 1.9.9c)
*    `NSFW сайты.netfix-mod` — Разблочит домены сайтов для взрослых.
